# ☁️ CloudLeak: Intelligent Multi-Cloud Cost Optimization Engine

> Enterprise-grade DevOps dashboard and waste detection engine designed to identify, analyze, and eliminate multi-cloud infrastructure leakage across AWS, GCP, and Azure.

---

## 🚀 Key Features

* **Executive Dark SaaS Interface**: High-contrast, responsive dashboard styled like modern cloud management platforms (Datadog / AWS Cost Explorer).
* **Automated Waste Detection**: Identifies idle EC2/VM instances, unattached EBS/persistent volumes, and over-provisioned staging databases.
* **Multi-Cloud Scope & Filtering**: Dynamic telemetry slicing across AWS, GCP, and Azure environments.
* **Actionable Exporting**: Built-in CSV audit reporting for engineering leads and finance stakeholders.

---

## 🛠️ Tech Stack

* **Frontend**: Python, Streamlit, Plotly (Interactive Data Visualization)
* **Backend**: FastAPI, Uvicorn (Async REST API Framework)
* **Infrastructure**: Docker, Docker Compose, PowerShell Orchestration
